# Runtime libraries

Download the **FaceRecognition-Linux-v2** Drive folder into `cpu/`:

https://drive.google.com/drive/folders/11XBHzGVosF7742_LdToXG4dZ160uYQCu?usp=sharing

Expected files (CPU):

- `libFaceRecognitionSDK.so`
- `libfar-eng.so`, `libfar-sec.so`, `libonnxruntime.so.1`, `far.fpk`
- `libfal-eng.so`, `fal.fpk`

Then `./run.sh` or `docker compose up --build`.
